Projets d'application

01 / Web

TaskFlow — gestionnaire de tâches collaboratif

Application web permettant à une équipe de créer des tableaux de tâches, d'assigner des échéances et de suivre l'avancement en temps réel via WebSocket. Projet réalisé en groupe de quatre sur un semestre.

  • React
  • Node.js
  • MongoDB
  • Socket.IO
02 / Mobile

SkyCast — application météo Android

Application mobile affichant les prévisions locales et une carte des précipitations, avec géolocalisation et gestion de plusieurs villes favorites. Consommation d'une API météo publique et mise en cache locale.

  • Kotlin
  • Android Studio
  • REST API
  • Room (SQLite)
03 / Algorithmique

Labyrinthe & IA — jeu 2D en Python

Jeu de labyrinthe généré procéduralement, avec un adversaire contrôlé par un algorithme de recherche de chemin (A*). Projet individuel destiné à mettre en pratique les structures de graphes vues en cours.

  • Python
  • Pygame
  • Algorithme A*
04 / Web & BDD

Bricoline — boutique en ligne fictive

Site e-commerce complet avec catalogue, panier, gestion de compte client et back-office d'administration des stocks. Projet de fin de semestre autour du modèle relationnel et de la sécurisation des formulaires.

  • PHP
  • MySQL
  • HTML / CSS / JS
